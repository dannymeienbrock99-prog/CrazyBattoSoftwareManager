# Sicherheit

## Unterstützte Version

Aktuell wird nur Version 0.1.x gepflegt.

## Wichtige Einschränkung

SoleLink Diagnostic ist ein Nur-Lese-Inspektor. Pull Requests oder Builds, die
unbekannte Werte an Motor-, LED-, Profil- oder Firmware-Merkmale senden, dürfen
nicht ohne dokumentierte Paketzuordnung, Wertebegrenzung und Hardwaretests
übernommen werden.

## Sicherheitsproblem melden

Keine privaten Bluetooth-Adressen, Seriennummern, Kontodaten oder vollständigen
HCI-Protokolle in öffentliche Issues hochladen. Sensible Aufzeichnungen zuerst
lokal kürzen und anonymisieren.
